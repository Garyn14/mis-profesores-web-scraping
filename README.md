# MisProfesores.com Web Scraper

This repository contains a Python script that scrapes data from [MisProfesores.com](https://misprofesores.com), a website where students rate and review their professors.  

The extracted information is used for research purposes and will later feed into a larger recommendation system for students at **Universidad Nacional Mayor de San Marcos (UNMSM)**.

---

## Description
- Collects professor data such as names, ratings, and comments.  
- Built with **Python** using `BeautifulSoup`.  
- Stores the results in a structured format (CSV/JSON).
